Nguyên nhân có thể gặp:

  • Bạn nhập nhầm hoặc thiếu ký tự trong chuỗi 5 chữ số.

  • Ngoại lệ InvalidBorrowCodeException đã được ghi log bởi AOP @AfterThrowing.
